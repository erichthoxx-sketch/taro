# Таро-кабинет

Личное веб-приложение таролога: колоды с типовыми значениями и своими наработками, материалы, расклады, клиенты и бесконечный чат с нейросетью Gemini по каждой колоде.
Работает в браузере на телефоне и компьютере (можно добавить на экран «Домой»), данные синхронизируются через Firebase, вход по почте.

- **Адрес:** https://erichthoxx-sketch.github.io/taro/
- **Нейросеть:** Gemini от Google, бесплатно. Ключ берётся на aistudio.google.com/apikey и вписывается в настройках приложения (шестерёнка). Из России для Gemini нужен VPN.
- **Колоды:** шаблоны Уэйта, Тота, Марселя, Ленорман и пустой оракул — `js/decks.js`; схемы раскладов — `js/spreads.js`.
- **ИИ:** запросы к Gemini — `js/ai.js`; что нейросеть знает и как помнит переписку — `js/brain.js`.
- **Расчёты** (карты рождения, база знаний для ИИ, разбор ответа): `js/tcalc.js`. Тесты: `npm test`.
- На своём компьютере (localhost) приложение запускается в пробном режиме: данные только в этом браузере.
